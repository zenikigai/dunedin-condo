Dunedin Condo Website

Files:
- index.html — complete standalone website. No external CSS or JavaScript dependencies.

Quick preview:
- Double-click index.html in a browser.

Free hosting options:
1. Cloudflare Pages: create a Pages project and upload/deploy this folder.
2. GitHub Pages: create a repository, upload index.html to the repository root, then enable Pages in repository Settings > Pages.

The site is fully self-contained except for the external Zillow link. All calculators run locally in the visitor's browser.
